## Exercise: Prompt Engineering (10 mins)

Start with this basic prompt:

> _"My Julia script for solving partial differential equations is too slow. Please make it faster."_
>
> _\[code snippet\]_

Imagine a very specific scenario and rewrite it in the
> **Persona + Context + Task + Constraints + References**

framework.
